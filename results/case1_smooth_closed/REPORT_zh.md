# 平滑闭合耦合

共享隐角度将三瓣目标曲线与压缩、旋转后的终止曲线配对。实验比较同一个三头模型在有、无几何校正时的端点误差和路径偏离。

## 实验设置

| 设置 | 数值 |
|---|---:|
| 模型参数量 | 130566 |
| 训练随机种子 | 1234 |
| 训练步数 | 20000 |
| 评估随机种子 | 20261002 |
| 端点对数 | 1024 |
| 反向更新次数 | 60 |
| 最大校正强度 | 0.12 |

两组采样使用相同的训练权重、端点和初始噪声。校正强度随时间按正弦平方变化。推理输入为当前状态、时间和给定终止端点。解析参考曲线用于计算路径距离，每个时刻离散为 1200 个点。

## 结果

| 指标 | 无校正 | 有校正 | 定义 |
|---|---:|---:|---|
| 平均端点距离 | 0.01359 | 0.00925 | 预测终点到配对真实终点的直线距离，对样本取平均 |
| 平均路径偏离 | 0.03416 | 0.01217 | 路径在 61 个时刻到相应参考曲线的最近距离，对时间和样本取平均 |
| 按坐标计算的均方根误差 | 0.01075 | 0.00712 | 端点误差在样本和两个坐标上的平方平均值的平方根 |
| 平均多走路程 | 0.01707 | 0.01252 | 路径总长度减去首尾直线距离，对样本取平均 |
| 平均累计转角 | 115.4 度 | 154.1 度 | 相邻位移单位方向向量的夹角沿路径累加，对样本取平均 |
| 完整网络调用次数 | 60 | 120 | 校正每一步增加一次完整网络调用 |

距离采用本案例的坐标单位。表中转角采用单位方向向量计算；结果文件的 `legacy_turning_degrees` 记录分母加 `1e-8` 时的计算值。
